# Portfolio

Hudson Farley's repository where all projects live.

Live site: https://hdsn-frly.github.io/Portfolio/

## Structure

- `index.html`: language picker (English / Español)
- `en/index.html`: English portfolio page
- `es/index.html`: Spanish portfolio page
- `en/images/`: photos for the gallery (photo-1.jpg, photo-2.jpg, ...)
- `assets/style.css`: shared styles
- `assets/resume.pdf`: résumé (add your file here)

## Editing

Open `en/index.html` and replace anything marked `TODO` or wrapped in [brackets]. Commit to `main`; GitHub Pages redeploys in a minute or two.
